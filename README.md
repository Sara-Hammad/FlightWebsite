Flight Booking Website
A comprehensive platform designed for flight booking and management, catering to both companies and passengers. The project provides a robust interface for users to register, search, and manage flights seamlessly.

Features
Users
Company:

Manage company profile with details like name, bio, address, location, logo, etc.
Add and manage flights.
View lists of registered and pending passengers.
Cancel flights with automatic refund processing.
Passenger:

Manage passenger profile with personal details.
Search and book flights.
Track completed and current flights.
Communicate with companies via messages.
Flight Management
Unique flight IDs.
Define itineraries (list of cities).
Manage passengers (registered and pending lists).
Set flight fees and schedule (start and end times).
Mark flights as completed or pending.
Pages
1. Register
Separate registration flows for companies and passengers.
Collect details such as email, name, password, phone number, and type (company/passenger).
2. Login
Email and password-based login for all users.
3. Company Dashboard
Add new flights with complete details.
View flight list with the ability to manage flights.
Access messages and passenger information.
4. Passenger Dashboard
Search for available flights.
View current and completed flights.
Manage bookings and communicate with companies.
5. Flight Information
Detailed view of flight itinerary, fees, schedule, and passenger details.
Options to book flights and message companies.
